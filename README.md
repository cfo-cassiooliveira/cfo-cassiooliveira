### Sobre mim

- Mais de **8 anos** desenvolvendo sistemas em **C#/.NET e Angular**, com **SQL Server e Oracle**.
- No projeto mais recente, implantei **SSO com Keycloak** em uma arquitetura de **microsserviços com RabbitMQ**:
  desenvolvi em Java um **SPI customizado** que roteia o login pelo domínio do e-mail (Active Directory via LDAP ou
  Identity Provider) e migra os usuários do legado sob demanda, validando o hash da senha.
- Vivência em produção com **deploy via Jenkins**, **Kubernetes na AWS** e monitoramento com **Graylog e Grafana**.
- Uso **IA (MCPs, Skills e Agentes)** para acelerar entregas e revisar código.
